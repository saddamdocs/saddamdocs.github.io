# Changelog

Every release of the stable channel, newest first. Each entry gives the schema version of PLAN 5.3:
an older release is safe to put back only if its schema version is the same as the current one.

## 0.0.2 (M0 skeleton)

Schema version: 1 (no notes are stored yet).

- No change but the version number. It exists so that the "A new version is ready" prompt and
  putting an older release back can be tried on the stable channel (spike A).

## 0.0.1 (M0 skeleton)

Schema version: 1 (no notes are stored yet).

- First skeleton: the app's name, version and channel on one screen, offline after one visit,
  installable from Brave, with the "A new version is ready" prompt.
- Proves the release path: release asset, checksum, and the manual "Deploy stable" workflow.
